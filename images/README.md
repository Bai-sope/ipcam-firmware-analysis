# 截图说明

本目录用于存放分析过程中的截图。

## 为什么不放实物照片

拆机照片可能包含设备外观、型号标识、序列号等信息，为避免泄露具体设备型号，实物照片不放入公开仓库。

## 需要的截图清单

如果要在本地复现，建议自行截图并放到本目录：

| 文件名 | 内容 |
|---|---|
| `01-binwalk.png` | binwalk 识别固件结构 |
| `02-filesystem.png` | 解包后的文件系统目录树 |
| `03-init-script.png` | `/etc/init.d/S20telnetd` 内容 |
| `04-firmae-boot.png` | FirmAE 仿真启动日志 |
| `05-web-page.png` | 仿真环境下的 Web 界面 |
| `06-poc-result.png` | 命令注入 PoC 执行结果 |
| `07-report.png` | 分析报告截图 |

## 脱敏要求

截图前请确认：

- [ ] 隐去设备型号、序列号
- [ ] 隐去 IP 地址（或改用 192.168.x.x 这类内网地址）
- [ ] 隐去 MAC 地址
- [ ] 隐去厂商 logo
